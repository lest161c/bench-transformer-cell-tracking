# Figure Provenance Trace — `report/main.pdf`

Audit of **all figures that actually appear in the rendered PDF**:
which `.tex` source uses them, and which Python script generates
them. Done by scanning every `\includegraphics` and every TikZ
environment in the report's `.tex` files.

## 1. Pipeline summary

```
report/.../*.tex      ─\includegraphics→   resources/figures/*.pdf
resources/figures/    ─ copied from  ←   curated/figures/*.pdf
curated/figures/      ─ generated by ←  curated/generate_report.py
                     OR  results/figures/*.pdf
results/figures/      ─ generated by ←  results/generate_plots.py
report/scripts/       ─ generated by ←  generate_amdahl_figure.py
```

Total figures **actually used** in `main.pdf`: **8**.
Total figures **on disk** under `report/resources/figures/`:
**37** (the rest are orphans — see §6).

## 4. How the figures land in the report

Three scripts write to **three different directories**. The
report's `main.tex` includes them via
`\graphicspath{{resources/figures/}}` (`main.tex:9`).
The pipeline today is **manual copy** of the figures from
`curated/figures/` and `results/figures/` into
`report/resources/figures/`. There is no `make` rule or shell
script that does this copy.

## 8. Reproducibility check

| Script                              | Output dir written  | Deterministic?        | Copy step to `report/resources/figures/` |
|-------------------------------------|---------------------|-----------------------|------------------------------------------|
| `curated/generate_report.py`        | `curated/figures/`  | uses pandas/np       | **manual copy** — no script                 |
| `results/generate_plots.py`         | `results/figures/`  | uses pandas/np       | **manual copy** — no script                 |
| `report/scripts/generate_amdahl_figure.py` | `resources/figures/` (default) | uses matplotlib only | writes directly — **no copy step**        |

To regenerate the full report PDF after a figure re-render, the
operator today must:

1. Run `python curated/generate_report.py`.
2. Run `python report/scripts/generate_amdahl_figure.py`.
3. Run `python results/generate_plots.py`.
4. Manually copy `curated/figures/*.pdf` into
   `report/resources/figures/`.
5. Manually copy `results/figures/*.pdf` into
   `report/resources/figures/`.
6. Run `latexmk main` from `report/`.

A `make_figures.sh` and a single `make_figures` target are
recommended.

## 9. Findings to investigate

- ❗ The orphan files in §6 should be removed from
  `report/resources/figures/` if they are not needed for the
  report PDF, **or** the report text should be updated to
  reference them.
- ❗ There is no automated copy / glue step between the three
  scripts and the report. A pre-commit hook or `make` target
  is recommended.
- ❗ The amdahl figure (`15_amdahl_law.pdf`) is written by the
  script directly to `report/resources/figures/`, but
  `curated/generate_report.py` writes to
  `curated/figures/`. Output-dir behaviour is **inconsistent**
  between scripts.
